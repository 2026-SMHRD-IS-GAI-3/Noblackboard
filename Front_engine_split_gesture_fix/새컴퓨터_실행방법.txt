AirNote를 다른 컴퓨터에서 실행하는 방법

1. 압축을 완전히 해제합니다.
2. Node.js LTS와 Python 3.10 이상을 설치합니다.
3. setup.bat을 한 번 실행합니다.
4. 설치가 끝나면 run_all.bat을 실행합니다.

주의:
- stt_server\.venv는 만든 컴퓨터의 Python 경로를 기억하므로 그대로 복사해 사용할 수 없습니다.
- GitHub의 Download ZIP에는 .gitignore로 제외된 다음 폴더가 포함되지 않습니다.
  stt_server\models
  stt_server\cuda-runtime
  stt_server\.venv
  node_modules
- models 폴더가 없다면 setup.bat이 faster-whisper medium 모델을 다시 다운로드합니다.
- 인터넷 없이 전달하려면 stt_server\models 폴더는 압축에 반드시 포함해야 합니다.
- 압축을 푼 뒤 stt_server\models 아래에 model.bin 파일이 있는지 확인합니다.
- 정상 파일 위치 예:
  stt_server\models\models--Systran--faster-whisper-medium\snapshots\(문자열)\model.bin
- cuda-runtime은 NVIDIA GPU 실행용입니다. 없어도 서버가 CPU int8로 실행될 수 있습니다.
- node_modules와 .venv는 새 컴퓨터에서 setup.bat으로 다시 만드는 것이 가장 안전합니다.
